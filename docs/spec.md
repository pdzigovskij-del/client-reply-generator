# Название
Client Reply Generator: генератор ответов клиентам

# Проблема
Ответы клиентам (жалобы, вопросы, возвраты, возражения) отнимают время
и получаются неровными: то слишком сухо, то слишком эмоционально.
Хуже всего, когда в ответе появляются обещания, которых компания не давала
(сроки, компенсации, скидки), и когда сложный случай не уходит менеджеру.

# Пользователь
Специалист поддержки или владелец малого бизнеса, который отвечает клиентам
в мессенджерах и по почте. Не программист: работает через простой веб-интерфейс.

# Основная функция
Вход:
- сообщение клиента
- тип ситуации: жалоба / вопрос / благодарность / возврат / возражение
- тон ответа: дружелюбный / деловой / эмпатичный
- контекст компании: правила возврата, сроки, график, что нельзя обещать
- количество вариантов ответа: 1-3
Обработка: запрос к языковой модели (GigaChat) со строгими правилами:
не выдумывать условия, не обещать вне контекста, при отсутствии ответа
в контексте честно сказать об этом.
Выход: варианты ответа, определённый тип ситуации и флаг «передать менеджеру»
с причиной.

# Формат результата
Веб-страница с готовыми к копированию вариантами ответа, отметкой
эскалации (если нужна) и определённым типом ситуации.

# Минимальный функционал (MVP)
- форма ввода (Streamlit)
- генерация 1-3 вариантов ответа в выбранном тоне
- ответ модели в JSON, разбор и вывод на экран
- флаг «передать менеджеру» с причиной
- обработка ошибок: пустой ввод, сбой API
- ключ API в .env, в репозитории только .env.example
Планируется позже:
- история ответов и экспорт
- переключение модели (GigaChat Lite/Pro, локальная через Ollama)
- набор тестовых обращений и сравнение промптов

# Технологии
Python 3, Streamlit, GigaChat API, python-dotenv.
Формат ответа модели: JSON. Тестовые обращения: tests/cases.json.
